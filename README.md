# Student Marks Analysis

A student performance analysis project with a Python data-analysis script and an interactive FastAPI dashboard. The included dataset is synthetic: it contains generated student identifiers and names, marks for five subjects, and class assignments.

## Features

- Cleans duplicate rows and fills missing marks with the mean for the corresponding subject.
- Reports overall and subject-level statistics, top students, and grade distribution.
- Generates subject-average and grade-distribution charts.
- Serves a dashboard with student, subject, grade, and class views, plus a searchable student explorer.

## Project files

| Path | Description |
| --- | --- |
| `student_marks.csv` | Synthetic source dataset |
| `analyze.py` | Cleans and analyzes the dataset, creates charts, and writes `ANALYSIS_REPORT.md` |
| `ANALYSIS_REPORT.md` | Generated analysis summary |
| `generate_data.py` | Regenerates the synthetic dataset |
| `backend/main.py` | FastAPI API and static dashboard server |
| `static/` | Dashboard HTML, CSS, and JavaScript |
| `subject_avg_bar_chart.png` | Subject average chart |
| `grade_distribution_pie_chart.png` | Grade distribution chart |

## Requirements

- Python 3.10 or newer
- Packages listed in `requirements.txt`

## Run the dashboard

From the project root, create and activate a virtual environment, then install the dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Start the development server:

```powershell
python -m uvicorn backend.main:app --reload
```

Open <http://127.0.0.1:8000> in a browser. The API documentation is available at <http://127.0.0.1:8000/docs>.

## Run the analysis

From the project root, run:

```powershell
python analyze.py
```

This updates both charts and writes the analysis summary to `ANALYSIS_REPORT.md`; it does not replace this README.

To generate a fresh synthetic dataset before analyzing it:

```powershell
python generate_data.py
python analyze.py
```

## API endpoints

- `GET /api/stats`
- `GET /api/subject-averages`
- `GET /api/grade-distribution`
- `GET /api/top-students?limit=10`
- `GET /api/class-performance`
- `GET /api/subject-class-heatmap`
- `GET /api/students?search=&page=1&per_page=20`

## Data and privacy

The checked-in CSV is generated by `generate_data.py` and uses synthetic names and IDs. Do not replace it with real student records or commit personal, confidential, or credential data.
